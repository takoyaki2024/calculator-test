# Calculator Test

A small Python desktop calculator created as a GitHub automation experiment.

## Features

- Addition, subtraction, multiplication, and division
- Decimal number support
- Friendly invalid-input handling
- Division-by-zero handling
- Automated unit tests
- GitHub Actions CI

## Run the app

Python 3 with Tkinter is required.

```bash
python app.py
```

## Run tests

```bash
python -m unittest discover -s tests -v
```

The calculator core uses only the Python standard library.
