# iPhoneで閲覧する

## 更新と起動

更新ZIPの `更新する.cmd` を開き、現在の `LocalMediaLibrary.exe` が入っている
フォルダを選びます。アプリを閉じた状態で更新してください。変更されたアプリ
ファイルだけを交換し、`data` のDB・設定・既存サムネイルには触れません。
対応する旧ビルドと違う場合は更新を中止します。

## 接続

1. PCとiPhoneを同じ自宅ネットワークへ接続する。
2. PCアプリの「設定」→「iPhone閲覧の設定を開く」。自宅のWi-Fi/有線LANの
   接続を選び「スマホ閲覧をON」。VPN/仮想アダプターは選ばない。
3. 初回は下記の専用証明書設定を行う。
4. SafariでPCに表示された `https://…:18766` を開く。
5. PCの8桁の接続コードを入力する（5分有効、入力は最大5回）。
6. iPhoneとPCの4桁の確認番号が一致したことを確認し、PCで「許可」を押す。
7. 漫画／画像／動画を選ぶ。動画は作品フォルダ→動画。動画の再生開始は自分で押す。
   漫画は前／次、画像はピンチ拡大。再生できない形式は画面に表示される。

Windowsがネットワーク許可を求めた場合、プライベートネットワークだけを許可する。
ルーターのポート開放、UPnP、外部への公開設定は行わない。
OFF・PCアプリ終了で全許可が失効する。許可は最長8時間。PC再起動後は再許可が必要。

## 初回の証明書 — 省略不可

PCがローカル生成した専用CA公開証明書をiPhoneにインストールする。
CAの署名用秘密鍵は保存しない。秘密鍵ファイルをスマホへ転送しない。

- PCの「公開証明書を保存」で `.cer` を書き出し、信頼できる手段でiPhoneへ転送する。
- または「初回証明書の取得を5分だけ開く」を押し、表示された `http://…:18767/LocalMediaLibrary.cer`
  をSafariで開く。この一時HTTP口が返すのは公開証明書だけで、メディアや接続コードは返さない。
  取得後「証明書の取得を閉じる」。5分でも自動終了する。
- HTTP取得は証明書の真正性を保証しない。信頼する前にPC画面のSHA-256と取得した証明書の
  SHA-256指紋を別の信頼できる経路で比較する。iOSで指紋を確認できない場合は、この
  HTTP方式だけで信頼せず、安全な転送・照合方法を確認する必要がある。
- iPhoneの「設定」→「一般」→「VPNとデバイス管理」でインストール後、
  「一般」→「情報」→「証明書信頼設定」でこの専用証明書の信頼を有効にする。
- HTTPS閲覧時に証明書警告が残る場合は、無視して進まず、証明書とPCのIPアドレスを確認する。
  PCのIPが変わった場合や証明書の期限更新時は再設定が必要。
- 使用をやめたら、iPhoneの専用証明書プロファイルも削除できる。

iPhoneの証明書確認UI・安全な初回転送の実操作は、この開発環境から確認できていない。
設定できたと断定しない。Apple手順: https://support.apple.com/102390

## 制限と確認待ち

原本は変更しない。大量の全件コピー、一括動画サムネイル生成、自動変換は行わない。
Windowsの共有フォルダ/ネットワークドライブはスマホ公開対象にしない。
対応はSafariが直接再生できる動画に限る（まずH.264/AACのMP4）。全Codec対応ではない。
一覧のサムネイルはPCで作成済みのキャッシュのみで、未生成は仮の表紙になる。
通信内容はTLSで保護するが、LAN管理者から通信量・接続先PC等まで隠す機能ではない。

Windows＋実際のiPhoneで証明書・接続・漫画表示・動画音声・シークの確認、および
意図しない外向き通信の監査が終わるまで、Phase 2実機完成とはしない。
